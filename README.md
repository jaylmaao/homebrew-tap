# jaylmaao/tap

Homebrew tap for [Agent Babysitter](https://github.com/jaylmaao/agent-babysitter) — a macOS menu bar monitor for AI coding agents.

```sh
brew install --cask --no-quarantine jaylmaao/tap/agent-babysitter
```

(`--no-quarantine` skips the one-time Gatekeeper prompt for this unsigned beta.)
